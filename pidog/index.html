R&D ObjectiveBuilding our own autonomous drone from source — sim to hardware to C2

Build a Custom Autonomous Drone
This is an R&D effort to build our own autonomous ground drone from first principles using PX4 open-source autopilot firmware. The SunFounder PiDog quadruped kit provides the physical platform — a 12-servo legged robot with onboard camera, ultrasonic distance sensor, and gyroscope, powered by a Raspberry Pi 4B (8 GB). By working from PX4 source, we gain full control over the autonomy stack.
Room Mapping & Autonomous Missions
Using the PiDog's camera and ultrasonic sensors, the robot will autonomously map indoor environments — building spatial models of rooms, detecting obstacles, and planning navigation paths. Missions can be defined, uploaded, and monitored from the ground station: survey a room, patrol a perimeter, track a moving object, or return to base.
Unity C2 Integration
The end goal is to link the physical PiDog to the Karneth Strata Unity C2 console, displaying live telemetry, camera feeds, and mapped environments alongside the simulated swarm. This demonstrates real + virtual asset command from a single operator station — the same MAVLink/DDS protocol stack used by the simulated fleet.
Platform for Future Development
The PiDog is the first physical asset in the KS ecosystem. Lessons learned here — sensor fusion, motor control, comms reliability, autonomy tuning — feed directly into future platforms: aerial drones, wheeled rovers, and multi-robot swarms. The PX4 stack scales from a robot dog to a full-size UAV.

Ground Control & Development ToolsInstalled and configured for immediate development

QGroundControl Installed
Primary ground control station. Mission planning, live telemetry dashboard, parameter tuning, joystick control. Connects to SITL over UDP automatically. Runs natively on Windows.
MAVProxy Installed
Command-line ground control. Scriptable, lightweight, ideal for automated testing and headless operations. Supports MAVLink message injection and custom mission scripting.
MAVSDK-Python Installed
Programmatic vehicle control via Python. Write autonomous mission scripts, integrate with external systems, bridge to the KS C2 console. gRPC-based, async-native.
Foxglove Studio Installed
Data visualization and diagnostics. Time-series plots, 3D scene rendering, log replay. Native ROS2/DDS support for future XRCE-DDS integration with PX4.
